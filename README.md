# SNAKE-AND-LADDERS---C-LANGUAGE
## Introduction (Aim or Motivation)
The purpose of this project is to:
Develop an interactive Snake and Ladder game in C.
Provide an engaging gaming experience for 1–4 players, including AI bots.
Demonstrate coding practices such as file handling, random number generation, and modular programming.

## Project Specification
### Key details of the project include:
Language: C
 Features:
Multiple players (1–4), with bot support.
Configurable board sizes: 5x10, 7x10, 10x10.
Snakes and ladders dynamically defined.
Player progress visualization and game results saved to a file.
Different background colors.
Sound effects for different functions.
